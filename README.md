# PortfolioHUB

## Sobre o projeto

Bem-vindo ao meu portfólio de projetos acadêmicos e pessoais!

Este repositório foi criado como parte do Bootcamp e tem como objetivo organizar e apresentar meus projetos desenvolvidos durante minha formação em Análise e Desenvolvimento de Sistemas (ADS).

## Objetivos

- Organizar projetos acadêmicos e pessoais.
- Praticar programação e desenvolvimento web.
- Aprender a utilizar Git e GitHub para versionamento.
- Compartilhar meus projetos e minha evolução profissional.

## Estrutura do repositório

- `projetos-academicos/` — trabalhos e atividades desenvolvidos na faculdade.
- `projetos-pessoais/` — projetos criados para praticar e aprender novas tecnologias.
- `documentacao/` — documentos e informações complementares dos projetos.
- `site/` — arquivos relacionados à página web do portfólio.

## Tecnologias e ferramentas

- Git
- GitHub
- HTML
- CSS
- JavaScript

## Projetos

Os projetos serão adicionados e documentados à medida que forem desenvolvidos.
